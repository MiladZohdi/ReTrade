Welcome to ReTrade, a simple JavaScript-based web application designed to enable users to upload and share second-hand items for sale.

This is a beginner-friendly project, and all functionality is implemented without using a back-end.
##
📌 Features

      Upload Ads: 
          Users can upload details of second-hand items they wish to sell, including:
            .A description of the item.
            .A price.
            .An image.
            .A contact number for potential buyers to reach out.
      Admin Approval:
          All ads go to a "Pending" section upon submission.
          An admin can log in and either approve or reject ads.
      Multiple Users: 
          Users can create as many accounts as needed to submit ads.
      No Back-End:
          All user data is stored temporarily in memory.
          Note: Refreshing the page will cause all data to reset to its initial state.

🚧 Limitations

      Data Persistence: 
          Since there is no back-end, refreshing the page clears all data.
      Responsiveness: 
          The app is not yet optimized for mobile or smaller screens but will be in future updates.
##
🛠 How to Use

    Clone or download the repository.
    Open the index.html file in your browser.
    Use the admin credentials to log in as an admin or create a user account to post ads.
